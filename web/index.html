Requisitos y diagnóstico

Abre League of Legends en este mismo PC. RiftSense lee el archivo lockfile del cliente y el Live Client Data API durante la partida.

Al importar un draft, el slot de tu rol se deja libre para comparar alternativas. Tu campeón hover aparece en el panel de champ select.

Si tu instalación está en una ruta personalizada:

LOL_LOCKFILE=D:\Riot Games\League of Legends\lockfile

La contraseña efímera del lockfile nunca sale del servidor local y no se muestra en la interfaz. Esto no automatiza el juego: solo lee datos.

El LCU no es una API oficial de Riot; puede cambiar con un parche. Si falla, la app sigue funcionando con la entrada manual.

    Leaguepedia

    API Cargo de lol.fandom.com: picks, bans, ganador, duracion, KDA e inventarios finales por jugador. Los nombres se cruzan con Data Dragon.

    Riot Data Dragon

    Catalogo oficial de campeones, objetos, runas y hechizos del parche. Los iconos se sirven desde el CDN de Riot.

    Riot API (opcional)

    Adaptador incluido para descargar high elo y timelines de compra con tu clave. El dataset pro funciona sin clave y sin límite de 24 h.

    Limites honestos

    El dataset son partidas profesionales, no tu elo. Las builds no incluyen el orden exacto de compra en todos los casos. Nada de esto garantiza victorias.
